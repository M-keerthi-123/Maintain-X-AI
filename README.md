# Maintain-X-AI
MaintainXAI is a machine maintenance and failure prediction project that analyzes industrial sensor data using Python, data preprocessing, EDA, visualization, and machine learning to predict failure risk. A web dashboard displays machine health, trends, and maintenance insights.
How to Run
Install the required Python libraries.
Open the project folder in VS Code or Command Prompt.
Run the main application file.
Open the provided local URL in a web browser to access the dashboard.
